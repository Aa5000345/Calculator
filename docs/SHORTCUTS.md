# 快捷键速查表

> 按 `F1` 打开应用内版本（含「自定义」Tab）。

---

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K` | 命令面板 |
| `Ctrl+Shift+K` | 显示 / 隐藏浮动计算器键盘 |
| `Ctrl+,` | 打开设置面板 |
| `Ctrl+1` ~ `Ctrl+9` | 切换到第 N 个可见模块 |
| `Ctrl+\` | 当前面板在分屏中打开 |
| `Ctrl+Shift+L` | 显示 / 隐藏侧边栏 |
| `Ctrl+Shift+H` | 手写输入 |
| `Ctrl+Shift+O` | 截图 / 图片识别 |
| `F11` | 专注模式（隐藏菜单栏 / 侧边栏） |
| `F1` | 快捷键速查表 |
| `Esc` | 关闭对话框 / 取消任务 |

---

## 输入框内

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 计算（输入框内） |
| `Ctrl+Enter` | 计算（不限焦点） |
| `Esc` | 取消运行中的任务；基础面板中清空输入 |
| `Ctrl+L` | 清空输入 |
| `Ctrl+Z` | 撤销上一次操作 |
| `↑` / `↓` | 召回历史表达式 |

## 结果面板

| 操作 | 功能 |
|------|------|
| 右键 | 弹出菜单：复制为文本 / LaTeX / JSON / CSV / Markdown；分享卡片；发送到其它面板；在新分屏打开 |

## 浮动键盘

| 按键 | 功能 |
|------|------|
| `2ⁿᵈ` | 切换二级函数（`sin` → `sin⁻¹` / `x²` → `x³` 等） |
| `=` | 触发当前面板 `calc()` |
| `C` | 清空当前输入框 |
| `⌫` | 退格 |
| `RAD` / `DEG` | 切换角度模式 |
| `📌` | 置顶开关 |
| `(` | 自动补全右括号，光标停在中间 |

---

## 命令面板

| 输入 | 行为 |
|------|------|
| `1+1` 或 `= 1+1` | 直接计算，结果内联显示 |
| `=` | 清空并等待表达式 |
| `>` | 显示分类列表 |
| `> theme` | 只匹配 `theme:` 前缀的命令 |
| `> 任意文本` | 只匹配命令，忽略历史与计算 |
| `jcjs` | 拼音首字母搜索（基础计算） |
| `Tab` | 在搜索框 / 列表间切换焦点 |
| `↑` / `↓` | 在列表中移动 |
| `Esc` | 关闭 |
| `Enter` | 执行选中项（计算模式下 = 复制到剪贴板） |

## 数学笔记本

| 快捷键 | 功能 |
|--------|------|
| `Shift+Enter` | 运行当前 cell 并跳到下一个 |
| `Ctrl+Enter` | 运行当前 cell（不跳转） |
| `Ctrl+Shift+Return` | 运行全部 |
| `Ctrl+S` | 保存为 `.mcnb` |
| `Ctrl+Shift+C` | 新增 code cell |
| `Ctrl+Shift+M` | 新增 markdown cell |

## 管道

| 语法 | 说明 |
|------|------|
| `\|` | 分隔步骤 |
| `to <unit>` | 单位 / 货币换算 |
| `as <fmt>` | 格式化（fraction / percent / sci / latex） |
| `<name>(<args>)` | 函数调用（sqrt / round / log…） |
| `<op> <expr>` | 算术（`* 2` / `+ 5` / `** 2`） |
| `_` | 占位符，指代上一步结果 |

**示例**：

```
1 km | to m
1 km | to m | * 2 | round(3)
100 USD | to CNY
5 | sqrt | round(2)
0.1 | as fraction
```

## 自定义快捷键

按 `F1` → 「自定义」Tab：

1. 找到要修改的命令
2. 点击「录制」
3. 按下想要的组合键
4. 确定

冲突的键位会标红。点击「恢复默认」可以重置单条或全部。

保存后立即生效，无需重启。

## 快捷键冲突排查

如果某个快捷键不起作用：

1. 按 `F1` → 自定义，检查是否被覆盖
2. 检查是否有其它应用占用了这个组合键
3. 尝试改成别的键
4. 若涉及 Qt 系统级快捷键，可能被系统占用

---

## 快捷键设计原则

- **全局**：应用级，任何面板都可用
- **输入框内**：只在输入框获得焦点时生效
- **面板级**：只在特定面板生效

冲突时，**更具体的上下文优先**。
